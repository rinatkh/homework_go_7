# 04. Вставка и удаление

Срез — это заголовок над базовым массивом. Изменение длины и сдвиг элементов — разные действия. Всегда используйте срез, возвращённый функцией.

## 04.1 `InsertAt`

```go
func InsertAt(values []int, index, value int) ([]int, bool)
```

**Что тренируем.** Освобождаем место внутри среза.

**Подсказка.** Какие прежние значения рискуют быть перезаписаны?

**Мини-пример.** `[1,3], index=1, value=2 → [1,2,3], true`.

**Частая ошибка.** Считать `index == len(values)` ошибкой. Это корректная вставка в конец.

**Сложность.** Худшее время O(n); память O(1) при свободной capacity или O(n) при росте массива.

## 04.2 `DeleteAt`

```go
func DeleteAt(values []int, index int) ([]int, bool)
```

**Что тренируем.** Сдвигаем хвост и освобождаем невидимую ячейку.

**Подсказка.** Область за новой длиной тоже принадлежит базовому массиву.

**Контракт.** Неверный индекс даёт исходный срез и false. При успехе бывшая последняя ячейка обнулена.

**Мини-пример.** `[10,20,30], index=1 → [10,30], true`.

**Частая ошибка.** Только сделать `values = values[:len(values)-1]`: удалится последний элемент, а не элемент по index.

**Сложность.** Время O(n-index), память O(1).

## 04.3 `DeleteUnordered`

```go
func DeleteUnordered(values []int, index int) ([]int, bool)
```

**Что тренируем.** Меняем порядок на скорость.

**Подсказка.** Каким свойством результата разрешено пожертвовать?

**Контракт.** Неверный индекс даёт исходный срез и false; при успехе хвост обнулён, порядок можно изменить.

**Мини-пример.** `[10,20,30,40], index=1 → [10,40,30]`.

**Частая ошибка.** Использовать функцию там, где порядок является частью результата.

**Сложность.** Время O(1), память O(1).

## 04.4 `RemoveElement` — адаптация LeetCode 27

```go
func RemoveElement(values []int, target int) int
```

Оригинал: https://leetcode.com/problems/remove-element/

**Что тренируем.** Перезаписываем входной срез без выделения нового.

**Подсказка.** Полезный результат — префикс исходного массива, а не новый срез.

**Контракт.** В этой адаптации сохраняем относительный порядок оставшихся значений; содержимое после k не проверяется.

**Мини-пример.** `[3,2,2,3], target=3 → k=2`, первые два значения — `[2,2]`.

**Частая ошибка.** Удалять через `append` внутри range по тому же срезу: индексы сдвигаются, и соседнее совпадение можно пропустить.

**Сложность.** Время O(n), память O(1).

## 04.5 `MergeSorted` — идея LeetCode 88

```go
func MergeSorted(first, second []int) []int
```

Оригинал: https://leetcode.com/problems/merge-sorted-array/

**Что тренируем.** Используем сортировку входов вместо повторного поиска минимума.

**Подсказка.** Какая информация уже известна благодаря сортировке обоих входов?

**Контракт.** Оба входа неубывающие, не меняются; ответ находится в новом массиве. В отличие от оригинала 88, здесь не требуется запись в первый вход.

**Мини-пример.** `[1,3,7] + [2,2,8] → [1,2,2,3,7,8]`.

**Частая ошибка.** Забыть остаток одного среза после завершения основного цикла.

**Сложность.** Время O(n+m), дополнительная память O(n+m) для нового результата.
