# 01. Сложность: сначала считаем понятные шаги

В этом разделе `n` — длина входного среза, если отдельно не сказано иное. Под дополнительной памятью понимаем память сверх уже переданного входа.

## 01.1 `MiddleElement`

```go
func MiddleElement(values []int) (int, bool)
```

**Что тренируем.** Отличаем размер входа от числа выполненных операций.

**Подсказка.** Как определить середину, не перебирая элементы?

**Мини-пример.** `[10, 20, 30, 40] → 30, true`; `[] → 0, false`.

**Частая ошибка.** Писать цикл, который доходит до середины. Он даст правильный ответ, но превратит O(1) в O(n).

**Сложность.** Время O(1), память O(1).

## 01.2 `Sum`

```go
func Sum(values []int) int
```

**Что тренируем.** Видим один полный проход по входу.

**Подсказка.** Какое значение должно быть у накопителя для пустого входа?

**Мини-пример.** `[-2, 1, 4] → 3`.

**Частая ошибка.** Возвращать результат внутри цикла: тогда функция обработает только первый элемент.

**Сложность.** Время O(n), память O(1).

## 01.3 `CountEven`

```go
func CountEven(values []int) int
```

**Что тренируем.** Считаем операции в цикле с условием.

**Подсказка.** Как проверить чётность отрицательного числа?

**Мини-пример.** `[-2, 1, 4, 7, 8] → 3`.

**Частая ошибка.** Считать отрицательное чётное число нечётным. В Go `-2%2 == 0`.

**Сложность.** Время O(n), память O(1).

## 01.4 `PairCount`

```go
func PairCount(values []int) int
```

**Что тренируем.** Отличаем вложенные циклы от последовательных.

**Подсказка.** Чем пара индексов отличается от пары значений?

**Мини-пример.** Срез длины `4 → 6` пар; длины `1 → 0`.

**Частая ошибка.** Начинать внутренний цикл с нуля: появятся пары элемента с самим собой и дубликаты.

**Сложность.** При циклах время O(n²), память O(1). Формула `n*(n-1)/2` даст O(1), но сначала реализуйте понятный вариант и объясните оба.

## 01.5 `HalvingSteps`

```go
func HalvingSteps(n int) int
```

**Что тренируем.** Узнаём O(log n) через повторное уменьшение задачи вдвое.

**Подсказка.** Округление вверх важно для нечётного n. Учитывайте границу int.

**Контракт.** При каждом делении округляем вверх. n <= 1 даёт 0; допустим n вплоть до math.MaxInt.

**Мини-пример.** `16 → 4` шага; `17 → 5`; `1 → 0`.

**Частая ошибка.** Писать `n--`: тогда размер уменьшается на единицу и получается O(n), а не O(log n).

**Сложность.** Время O(log n), память O(1).
