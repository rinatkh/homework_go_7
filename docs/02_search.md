# 02. Поиск в срезе

Перед бинарным поиском явно проверьте предпосылку: срез должен быть отсортирован по возрастанию. Функции не сортируют вход сами.

## 02.1 `LinearSearch`

```go
func LinearSearch(values []int, target int) int
```

**Что тренируем.** Самый прямой поиск без требований к порядку данных.

**Подсказка.** Индекс 0 — допустимый ответ, а не признак отсутствия.

**Мини-пример.** `[4, 2, 7], target=7 → 2`; `target=9 → -1`.

**Частая ошибка.** Возвращать `0` при отсутствии: индекс ноль является правильной позицией первого элемента.

**Сложность.** Лучший случай O(1), худший O(n), память O(1).

## 02.2 `FirstIndex`

```go
func FirstIndex(values []int, target int) int
```

**Что тренируем.** Формулируем, какое именно вхождение нужно вернуть.

**Подсказка.** Какое из нескольких совпадений требует контракт?

**Мини-пример.** `[4, 2, 7, 2], target=2 → 1`.

**Частая ошибка.** Сохранять индекс и идти до конца: получится последнее, а не первое вхождение.

**Сложность.** Время O(n), память O(1).

## 02.3 `BinarySearch`

```go
func BinarySearch(values []int, target int) int
```

**Что тренируем.** Уменьшаем область поиска вдвое.

**Подсказка.** Сформулируйте инвариант диапазона до выбора условий цикла.

**Мини-пример.** `[-3, 0, 4, 8, 12, 15], target=12 → 4`.

**Частая ошибка.** Присваивать `left = middle`: при двух оставшихся элементах граница может перестать двигаться, и цикл станет бесконечным.

**Контракт.** Вход неубывающий; любое совпадение или -1; вход не меняется.

**Сложность.** Лучший случай O(1), средний/худший O(log n), память O(1).

## 02.4 `SearchInsert` — адаптация LeetCode 35

```go
func SearchInsert(values []int, target int) int
```

Оригинал: https://leetcode.com/problems/search-insert-position/

**Что тренируем.** Бинарный поиск границы, а не только точного совпадения.

**Подсказка.** Ответ должен оставаться осмысленным, даже если target отсутствует.

**Контракт.** Первая позиция со значением >= target, включая len(values); при повторах — первое вхождение.

**Мини-пример.** `[1,3,5,6], target=2 → 1`; `target=7 → 4`.

**Частая ошибка.** После неудачного обычного поиска возвращать последний `middle`: он не всегда совпадает с местом вставки.

**Сложность.** Время O(log n), память O(1).

## 02.5 `CountOccurrencesSorted`

```go
func CountOccurrencesSorted(values []int, target int) int
```

**Что тренируем.** Два бинарных поиска вместо полного прохода.

**Подсказка.** Одинаковые значения занимают непрерывный диапазон.

**Мини-пример.** `[1,2,2,2,4], target=2 → 3`; `target=3 → 0`.

**Частая ошибка.** Найти одно совпадение и расширяться в обе стороны линейно: на срезе из одних target это станет O(n).

**Сложность.** Время O(log n), память O(1).
