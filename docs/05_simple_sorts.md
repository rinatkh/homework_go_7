# 05. Простые сортировки

Все три учебные сортировки меняют входной срез на месте. Перед кодом проговорите, какая часть уже находится в правильном состоянии после каждого внешнего прохода.

## 05.1 `BubbleSort`

```go
func BubbleSort(values []int)
```

**Что тренируем.** Меняем соседей и видим, как максимум «всплывает» вправо.

**Подсказка.** Как понять, что следующий полный проход уже не нужен?

**Мини-пример.** `[3,2,1] → [2,1,3] → [1,2,3]`.

**Частая ошибка.** Идти до `len(values)`, а затем читать `values[i+1]`: последний индекс выйдет за границы.

**Сложность.** Среднее и худшее время O(n²), память O(1). С флагом отсутствия обменов лучший случай O(n).

## 05.2 `SelectionSort`

```go
func SelectionSort(values []int)
```

**Что тренируем.** Отделяем поиск минимума от одной перестановки.

**Подсказка.** Почему отсутствие обмена не доказывает готовность остальных позиций?

**Мини-пример.** `[3,1,2]`: минимум `1`, перестановка → `[1,3,2]`; затем минимум `2` → `[1,2,3]`.

**Частая ошибка.** Менять текущий элемент при каждой меньшей находке. Ответ может остаться правильным, но перестановок станет больше и рассуждение потеряется.

**Сложность.** Время O(n²) во всех случаях, память O(1).

## 05.3 `InsertionSort`

```go
func InsertionSort(values []int)
```

**Что тренируем.** Поддерживаем отсортированный префикс.

**Подсказка.** Какое утверждение верно о левой части перед очередной вставкой?

**Мини-пример.** `[1,4,2,3]`: вставляем `2` между `1` и `4` → `[1,2,4,3]`.

**Частая ошибка.** Не сохранить `current` до сдвига: его значение будет перезаписано.

**Сложность.** Лучший случай O(n), средний и худший O(n²), память O(1).

## 05.4 `IsSorted`

```go
func IsSorted(values []int) bool
```

**Что тренируем.** Проверяем свойство результата отдельно от конкретной сортировки.

**Подсказка.** Достаточно ли проверить только первый и последний элемент?

**Мини-пример.** `[1,1,2] → true`; `[1,3,2] → false`.

**Частая ошибка.** Считать равные соседние значения нарушением: нам нужен неубывающий порядок, поэтому равенство допустимо.

**Сложность.** Лучший случай O(1), худший O(n), память O(1).

## 05.5 `SortColors` — адаптация LeetCode 75

```go
func SortColors(values []int)
```

Оригинал: https://leetcode.com/problems/sort-colors/

**Что тренируем.** Используем маленький известный диапазон значений.

**Подсказка.** Учтите ограничение на множество значений и требуемое время.

**Мини-пример.** `[2,0,2,1,1,0] → [0,0,1,1,2,2]`.

**Частая ошибка.** Использовать общую сортировку и назвать её O(n): сравнивающая сортировка обычно требует O(n log n), а здесь линейность появляется из-за трёх известных значений.

**Сложность.** Время O(n), дополнительная память O(1).
